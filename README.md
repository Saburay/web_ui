Это приложение облегчающее визуализацию работы с аудиофайлами другого,более крупного проекта по озвучке текста(в перспективе клонирования голоса при озвучке)

This is an application that facilitates visualization of working with audio files of another, larger text-to-speech project (the prospect of cloning the voice during voiceover)
